# Awesome OPD Paper

精选值得认真阅读的同策略蒸馏（On-Policy Distillation，OPD）论文，保存中文 LaTeX 源码与阅读入口。收录重点是方法、实验和分析能帮助理解或改进 OPD，优先选择问题清楚、证据充分、对后续研究有参考价值的工作。

OPD 在学生模型自身采样的轨迹上，用教师模型的监督训练学生。本项目关注它如何迁移能力、训练数据起什么作用，以及哪些条件会影响训练效果和成本。

## 阅读与收录

每篇论文使用 arXiv ID 作为目录名，例如 `2609.04172/`。目录内保留中文源码、参考文献、插图和附带文件的原有相对路径，可从表中的入口阅读正文，再沿 `\input` 查看各节。编译状态以各目录说明为准；`2512.23075/` 的中文博客译写版已编译为 PDF，其余现有材料未验证 LaTeX 编译。关联博客沿用其链接论文的 arXiv ID，并在条目中注明材料类型。

新增论文时，核对 arXiv ID、标题和来源，将材料放入对应 ID 目录，并更新上表。收录说明应交代论文解决的问题和支持判断的证据；实验结果同时保留任务、模型与比较条件。中文译文用于辅助阅读，术语、公式和结论有疑问时对照原文。

论文及其附带材料的权利归原作者或相应权利人，使用时遵循各自的许可与引用要求。仓库维护规则的来源与许可见 [.agents/来源与取舍.md](.agents/来源与取舍.md)。
