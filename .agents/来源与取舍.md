# 维护规则来源与适配范围

本项目的三个维护技能及其共享参考、模板与 Notes 规则采用自 agent-maintenance[^maintenance]，来源提交为 `f2b7cdfe4c6ab96ed779f42c878e84b7042edf43`。采用内容保留在 `.agents/`，根 `AGENTS.md` 按论文仓库的工作范围编写。

agent-maintenance 的规则源自 DeepSeek Harness 提交 `571902028a75c64c1d767f4ae5fd099485f0ddf0`，经过中文翻译、裁剪与重组。所采用维护资源的 MIT 许可保存在 [LICENSE](LICENSE)，该许可适用于对应维护资源。

本项目采用文档维护规则、Git、EditorConfig 和临时文件忽略配置。论文是第三方材料，保留其内容和目录内的相对路径，编辑器规则仅作用于 Markdown。未引入维护包的开发依赖、检查脚本、hooks、CI 或 Markdown 预览资源；共享参考中关于其他类型项目的建议按实际需要使用。

Notes 入口已去除未接入脚本的命令。当前没有归档记录和冻结检查工具，启用归档前须建立清单及可信 Git 基线校验。维护包自身的过程记录未复制到本项目。
