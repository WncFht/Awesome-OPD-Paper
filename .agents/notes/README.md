# Agent Notes

Agent Note 保存论文材料与当前使用文档不能充分表达的长期理由、替代方案和代价。相同决定更新原记录，局部机械修改不创建记录。

生命周期、分类和中文章节见[记录规范](../references/decision-notes.md)，新建记录时可采用 [proposed](../templates/proposed.md) 或 [implemented](../templates/implemented.md) 模板。已实施决定在事实变化时同步更新。

当前由维护者检查记录格式与链接。归档前须接入哈希清单与可信 Git 基线校验，规则见[归档要求](archived/AGENTS.md)。
